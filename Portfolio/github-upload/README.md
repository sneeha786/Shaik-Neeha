# Shaik Neeha — Portfolio

A personal portfolio for Shaik Neeha, a first-year B.Tech Computer Science student at Aditya University, graduating in 2030 and interested in cybersecurity.

The design combines a black universe background, light and dark emerald accents, running code, a particle globe, and smooth camera movement between five chapters. A skippable hourglass intro opens the site. Visitors can also explore the profile through an interactive terminal.

## Run locally

Install Node.js, then run:

```sh
npm start
```

Open **http://127.0.0.1:4173**. There are no package dependencies to install and no build step.

## Files

- `index.html`: page content and opening screen.
- `style.css`, `immersive.css`, `intro.css`, `scene-glide.css`, `palette.css`: layout, effects, and colors.
- `immersive.js`: universe graphics and chapter navigation.
- `intro.js`: hourglass opening sequence.
- `script.js`: interactive portfolio terminal.
- `server.cjs`: local static preview server.

The repository root contains the authored website source, ready to host on a static web server. Google Fonts require an internet connection; fallback fonts are provided. Motion can be paused, and reduced-motion preferences are respected.

This repository contains the current website source. Hosting credentials and platform-specific deployment metadata are excluded.
